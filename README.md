# MIVA MIT Academic Portfolio 2 – Query Optimization

## 1. Project Overview

This project focuses on database query optimization using PostgreSQL. It demonstrates how SQL queries can be analysed, 
improved, and executed more efficiently to enhance database performance.

The project forms part of the Master of Information Technology (MIT) academic portfolio at MIVA Open University.

## 2. Project Objectives

The objectives of this project are to:

- Understand database query optimization techniques.
- Identify inefficient SQL queries.
- Analyse query execution plans.
- Apply indexing techniques to improve query performance.
- Compare query execution before and after optimization.
- Evaluate the impact of optimization on database efficiency.

## 3. Tools and Technologies

| Tool | Purpose |

| PostgreSQL | Relational Database Management System |

| GitHub | Project documentation and version control |

## 4. Case Study

**Proposed Case Study:** University Student Management System.

The project uses a relational database containing student, department, lecturer, course, semester, enrollment, and academic result information.

The database provides a practical environment for testing SQL queries and evaluating optimization techniques.

## 5. Project Scope

The project covers:

1. Database and table preparation.
2. Identification of inefficient SQL queries.
3. Query execution plan analysis.
4. Query optimization using appropriate SQL techniques.
5. Index creation and evaluation.
6. Before-and-after performance comparison.
7. Documentation of findings and recommendations.

## 6. Expected Deliverables

- Database structure and sample data.
- SQL queries before optimization.
- Query execution plans.
- Optimized SQL queries.
- Indexing scripts.
- Performance comparison results.
- Final project report.
